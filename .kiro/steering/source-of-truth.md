# Source and safety rules

- Treat every excerpt as a candidate requiring human review. The tool must not claim a person is eligible, an award was granted, or a submission was sent.
- The user pastes the notice. The optional URL is a reference only; the prototype does not fetch it, store the text on a server, or connect to a DUA account.
- Quote the supplied text without inventing missing requirements. If dates are ambiguous, incomplete, invalid, or multiple, do not invent an ISO date or a time zone.
- Comparison means literal added and removed lines; it does not decide whether rules legally changed.
- A calendar download is a day-long reference, offered only after the user marks an explicit deadline excerpt reviewed. It does not schedule an event or invent the closing time.
- Keep the example visibly fictional. No production user data, API keys, paid calls, or private DUA source code belong in this isolated project.
- English and Portuguese are supported. Accessible controls and small-screen layouts matter.
- Critical-reading alerts quote the line that triggered them and suggest a question; they never call a clause unfair, illegal or acceptable.
- A gap states that something was not detected in the supplied text. Never say the notice lacks it.
- Countdown milestones are suggestions for the user's own planning. Never present them as organiser dates, and never count down from an ambiguous, incomplete or invalid date.
- Readiness counts what the user ticked. It is never a score of eligibility or chance of success.
- PDF text is read locally from the text layer only. Never OCR, guess or "repair" a page; say which pages had no text.
- A period exposes only its explicit closing date. Never complete a missing year, and never let a publication, opening, results or execution date drive the countdown.
- The e-mail draft and the calendar file are prepared for the user, who sends or imports them. The page never sends anything.
- Evaluation reports state what was measured and what was not. Do not publish third-party notice text in this repository.
