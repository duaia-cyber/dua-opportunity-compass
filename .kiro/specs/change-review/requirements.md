# Change review — requirements

When comparing two pasted versions, label added and removed lines with possible topics to help the user prioritise review. Labels are tentative and incomplete; they do not establish that a rule or legal condition changed. Matching is local and deterministic. The comparison counts literal lines and does not compare order.

Use the existing analysis and signal readers for both additions and removals. Preserve the exact line and direction. The user can choose All changes or Lines with possible topics. The filter uses a native control, supports English and Portuguese, keyboard use and small screens, and defaults to all changes. Do not add a new-in-version badge: duplicate line counts are not proof of semantic novelty. No network, accounts or dependencies.
